# Projekt: Inan (Mathematik LK Q1)

## Überblick & Ziel
- Eigenständiges Webportal und Übungsmaterial für den Mathematik-Leistungskurs (Q1, Schuljahr 2026/27).
- Veröffentlicht über GitHub Pages unter `https://feyhat79.github.io/Inan/`.

## Tech-Stack & Befehle
- HTML5, CSS3, JavaScript
- KaTeX für mathematischen Formelsatz via CDN
- Git / GitHub Pages (Root-Deployment `/` aus Branch `main`)

## Projektspezifische Regeln
- Alle Arbeiten finden isoliert in diesem Ordner statt.
- KaTeX-Pflicht für alle mathematischen Formeln (`$...$` bzw. `$$...$$`).
- Professionelles, gymnasiales Design (keine bunten KI-Emojis).
- Datenschutz: Klausuren, Notenlisten und Musterlösungen verbleiben lokal und werden niemals nach GitHub gepusht.
